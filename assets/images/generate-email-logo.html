📸 How to Create the PNG

  1. Right-click on the logo above
  2. If using Chrome: Use "Inspect" → right-click the element → "Capture node screenshot"
  3. Or take a screenshot and crop tightly around the logo
  4. Save as: email-logo.png
  5. Upload to: assets/images/email-logo.png

Tip: The background should be transparent or match the blue (#1e40af)

Recommended final size: ~200px wide
