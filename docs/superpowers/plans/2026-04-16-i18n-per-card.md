# Plan, i18n Per Card (Cardify)

## Goal
Each employee card supports EN + AR for the most-visible content. Public card honours `?lang=`,
remembers choice via cookie, sets `dir="rtl"` for AR, falls back to EN when AR missing.

## Scope (v1)
- **In:** name, position (title), bio_text, services (title/description), testimonials (name/quote)
- **Out:** offers (table not on main yet, follow-up)

## Schema (migration 049)
- `employees` already has `name_en/name_ar/position_en/position_ar`, no change.
- ADD column `employee_card_sections.bio_text_ar TEXT` (existing `bio_text` = EN primary).
- NEW `employee_card_services_i18n` (service_id, locale, title, description, UNIQUE(service_id,locale)).
- NEW `employee_card_testimonials_i18n` (testimonial_id, locale, name, quote, UNIQUE(testimonial_id,locale)).
- Backfill: lazy, read EN base columns when no AR row found.

## Helper (CardSections.php)
- `resolveLocale()`, `?lang=` then cookie `cardify_locale` then default 'en'; sets cookie when query present.
- `isRtl($locale)`, true for 'ar'.
- `tColumn($row, $base, $locale)`, pick `${base}_<locale>`, fallback to `${base}_en` then `${base}`.
- `loadServicesLocalized($eid, $locale)` and `loadTestimonialsLocalized($eid, $locale)`, overlay i18n rows on base.
- `upsertServiceTranslation` / `upsertTestimonialTranslation`, UPSERT into i18n tables.
- `saveMaster` extended with `bio_text_ar`.

## Admin UI (company/views/employee.php)
- Bio: side-by-side EN textarea + AR textarea (dir="rtl").
- Services row: 2nd line of AR title/description fields when adding.
- Testimonials row: 2nd line of AR name/quote when adding.
- Existing rows: edit-in-place is a follow-up (v1 = on-add only).

## Public render (digital_card.php)
- Compute `$locale` (query/cookie). Set cookie when `?lang=` present (7-day expiry).
- `<html lang dir>` reflects locale. Add Google `Noto Sans Arabic` font when AR.
- Localized name/position/companyName via `tColumn`. Localized bio via `bio_text_ar` w/ EN fallback.
- Services/testimonials use `loadXxxLocalized` (overlay AR over EN baseline).
- Top-right small switcher: EN | عربي toggle, preserves rest of URL.

## Verification
- `php -l` every touched file.
- Migration committed as `.sql` + `.php` runner (idempotent).
- After deploy: `curl https://cardify.om/<slug>/?lang=ar` and grep `dir="rtl"`.

## Constraints honored
- Cards with no AR continue rendering EN (fallback).
- Paymob, Fabric.js, Wallet, Analytics, Dynamic QR untouched.
