Government identity import, 4 October 2026

Source: `_الهوية الحكومية الموحدة.pdf`, Unified Government Identity Guide, 2025 edition, 60 PDF pages. The source SHA-256 and each crop are recorded in `data/government-identity-2025.json`.

Scope: 49 named government entities from PDF pages 24–31, plus the Sultanate of Oman state logo from PDF page 9. Each gets a separate company profile. Existing 26 profiles retain their IDs and slugs; 24 profiles are created. Both Arabic vertical and bilingual horizontal layouts are extracted, with original colour, black and white variants. Six entities also receive the international layout from PDF page 33, labelled for use outside Oman only. Historical designs, repeated application examples and prohibited modifications are not presented as current entity logos.

Files: SVG with font outlines, vector PDF, transparent PNG at 512/1024/2048 for originals, 2048 PNG for monochrome variants, and lossless WebP. Per-entity ZIP bundles include both layouts, monochrome variants, optional international assets and a source manifest. Download access continues to use the existing unlock flow and rate limit. The endpoint accepts only supported formats and resolves each path beneath the logo storage directory.

Import: upload the extracted assets to `storage/logos/indexed/government-2025/`. Run migration 173, then `php scripts/import-government-identity.php data/government-identity-2025.json` to inspect the dry run. Append `--apply` to import. The importer checks every source asset, rejects ambiguous identities or protected statuses, backs up existing database rows under the private directory, and writes all rows inside one transaction. It does not delete old logo files or invent registry, contact or account data. Source profile text identifies the government guide; government bodies are not labelled as large commercial enterprises.

Reproduction: Python 3 with PyMuPDF and Pillow, `python3 scripts/extract-government-identity.py SOURCE.pdf OUTPUT --companies COMPANY_NAMES.json`. Entity names are transcribed from the original guide. Source contours are retained; no image tracing or generated logos are used. Runtime assets stay outside Git, consistent with the existing logo-storage policy.

Validation: all 50 entity packs are visually inspected through contact sheets, including Arabic, English and international layouts. PHP syntax, download-path unit tests, English/Arabic key parity and transparent/vector asset checks run before publication. Live verification checks every profile in both languages and at mobile and desktop widths, plus representative original, monochrome, Arabic, PDF and ZIP downloads.
